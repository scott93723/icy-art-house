# ICY Art House

A real-time 3D artist villa for **ICY**, filled with self-portraits.

🔗 Live concept based on the original [Valley Villa](https://24rokdmtagiye.ok.kimi.link/) architectural model.

## Preview

Open `icy-villa.html` in any modern browser to explore the villa:

```bash
open icy-villa.html
```

## Features

- Procedurally generated gallery space with concrete base, wooden beam, and floor-to-ceiling glass
- 9 framed self-portraits of ICY, generated as abstract canvas paintings
- Interactive camera controls (drag, scroll, right-click pan)
- Soft spotlighting for each artwork

## Tech Stack

- [Three.js](https://threejs.org/) (loaded via CDN)
- Vanilla HTML / CSS / JavaScript
