# ICY Art House

A real-time 3D artist villa for **ICY**, filled with her own artworks and portraits.

🔗 Live concept based on the original [Valley Villa](https://24rokdmtagiye.ok.kimi.link/) architectural model.

## Preview

🌐 **Live site**: https://scott93723.github.io/icy-art-house/

Open `index.html` in any modern browser to explore the villa locally:

```bash
# Suggested: serve via a local static server so image textures load correctly
npx serve .
```

## Featured Artworks

All images are placed inside the `images/` folder and displayed as framed paintings inside the 3D villa:

- **機器貓日常 Robot cat's daily** (2014) — pink, yellow, gray, blue
- **觀音系列 #w01** (2020)
- **心經觀音**
- **向日葵**
- **ICY Portrait**
- **ICY Studio**

## Features

- Real gallery space with concrete base, wooden beam, and floor-to-ceiling glass
- 9 framed original ICY artworks with title plaques
- Interactive camera controls (drag, scroll, right-click pan)
- Soft spotlighting for each artwork

## Tech Stack

- [Three.js](https://threejs.org/) (loaded via CDN)
- Vanilla HTML / CSS / JavaScript
